## Full Stack Development Project 

### **Goal**
- Install All Dependencies
- Create a Virtual enviorment 
- Start Contributing 

### Admin access
1. Copy `.env.example` to `.env`.
2. Set `VITE_ADMIN_EMAILS` to the Firebase Auth email address allowed to use `/admin`.
3. Restart Vite after changing `.env`.

Only allowlisted Firebase accounts can open the admin console. An empty allowlist denies admin access to everyone.
